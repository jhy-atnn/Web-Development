Character, village, clan, team, tailed-beast, kekkei-genkai, and Akatsuki records are requested directly from the
Dattebayo Naruto API. If it is unavailable, those features will not load until the service returns; the site does not
include an offline copy of API records. Hand-written biographies and descriptive lore remain local in `data/lore.json`.

Clan symbols and explicitly stated character eye colours are supplementary lookups from the Naruto Wiki's MediaWiki
API. Village and power cards use matching Naruto Wiki images when available; the power-card image lookups are loaded
as cards approach the viewport. Clan symbols and eye colours may be unavailable when the wiki has no matching file or
appearance description.
